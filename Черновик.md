# Тестирование этапа 8 — по пунктам

## Подготовка (30 секунд)

1. Закройте все окна «admin.log – Блокнот» (иначе открытый блокнот попадёт в слепок).
2. Проверьте версию: `bin\ScreenMemory.exe --version` → `ScreenMemory 0.8.0 (x64)`.
3. Все команды — из `cmd` в папке программы. Код возврата смотрите **отдельной строкой**, иначе `%errorlevel%` подставится до запуска и всегда покажет 0:
   ```
   bin\ScreenMemory.exe restore
   echo %errorlevel%
   ```

## Тест 1. Базовый прогон (5 минут)

1. **Делай раз** — сохранить текущее состояние:
   ```
   bin\ScreenMemory.exe save
   ```
   Ожидаемо: `Сохранено: … десктопов 5, мониторов 2, окон N`, код 0.
2. **Делай два** — посмотреть план, ничего не меняя:
   ```
   bin\ScreenMemory.exe restore --dry-run
   ```
   Ожидаемо: карта десктопов `по GUID … fallback 0`; строки «было бы применено», «было бы запущено»; **строки про десктоп 0 нет**; код 0.
3. **Делай три** — применить:
   ```
   bin\ScreenMemory.exe restore
   echo %errorlevel%
   ```
   Ожидаемо: «Применено: N, перенесено на другой десктоп: 0, z-order выставлен: N»; окна на своих местах/столах; если в системе есть окна админ-приложений (`Диспетчер задач`, `OpenConnect VPN`) — «ВНИМАНИЕ: … 5: Отказано в доступе», «не удалось восстановить: 2», **код 1**; иначе код 0.

## Тест 2. `admin.log`: перезапись, без даты, одно окно (3 минуты)

1. **Делай раз** — откройте `bin\admin.log` двойным щелчком и запомните число строк.
   Ожидаемо: строки вида `C:\Windows\SysWOW64\Taskmgr.exe | Диспетчер задач | move-blocked | desktop=Работа`; **даты нет**, кириллица читается нормально.
2. **Делай два** — не закрывая блокнот, снова выполните `bin\ScreenMemory.exe restore`.
   Ожидаемо: прежнее окно закрывается, открывается одно новое; на панели задач один блокнот, а не два-три.
3. **Делай три** — сравните содержимое: должно быть **ровно столько строк, сколько написано в отчёте** («требуют вмешательства человека: N»), и это только последний прогон (старых строк с прошлыми датами быть не может).

## Тест 3. Окна без своего десктопа (`fallback-desktop`) — 10 минут

Делаем на временном десктопе, реальные окна не страдают.

1. **Делай раз** — `Ctrl+Win+D` (новый десктоп), переименуйте его в `TestFallback`, откройте там **Блокнот** (и, для наглядности, окно Проводника).
2. **Делай два** — сохраните слепок, пока десктоп существует:
   ```
   bin\ScreenMemory.exe save
   ```
   Проверка, что десктоп попал в файл: `bin\ScreenMemory.exe --list` → в карте есть `TestFallback`.
3. **Делай три** — удалите десктоп `TestFallback` (Task View → правый клик по нему → «Удалить»; Windows перенесёт его окна на соседний стол). Имитируем «десктоп исчез после перезагрузки».
4. **Делай четыре** — план:
   ```
   bin\ScreenMemory.exe restore --dry-run
   ```
   Ожидаемо: в карте `fallback 1` (строка `[N] «TestFallback» → [0] «…» по: fallback`) и «уехало бы на десктоп 0 (целевой десктоп не найден): 2» (или 1, если открывали только Блокнот).
5. **Делай пять** — применяем:
   ```
   bin\ScreenMemory.exe restore
   echo %errorlevel%
   ```
   Ожидаемо: «Оказалось на десктопе 0 (целевой десктоп не найден): 2», предупреждение «окон на десктопе 0: 2 — сохранённых десктопов нет в системе…», **код 1**, а тестовые окна (Блокнот/Проводник) стоят на **первом** десктопе в тех же координатах.
6. **Делай шесть (обязательно)** — вернуть чистоту: закрыть тестовые окна и пересохранить слепок:
   ```
   bin\ScreenMemory.exe save
   ```
   Иначе следующий `restore` будет каждый раз честно сообщать про fallback.

## Тест 4. Окно админ-приложения (`move-blocked`) — 5 минут

1. **Делай раз** — откройте «Диспетчер задач» (он у вас запускается с правами администратора — именно это и нужно) и/или OpenConnect VPN.
2. **Делай два** — `bin\ScreenMemory.exe save`, затем сдвиньте окно Диспетчера мышью.
3. **Делай три** — `bin\ScreenMemory.exe restore; echo %errorlevel%`.
   Ожидаемо: «ВНИМАНИЕ: «Диспетчер задач»: SetWindowPlacement: 5: Отказано в доступе», строка `… | move-blocked | desktop=…` в `admin.log`, **код 1**; окно осталось там, куда вы его сдвинули (это ожидаемое поведение: UIPI, программа не имеет права двигать админ-окна).
4. **Делай четыре** — закройте Диспетчер и сделайте `save`, чтобы слепок соответствовал обычной работе.

## Тест 5. Консоли и «нет команды» (`console` / `no-command`) — по желанию
